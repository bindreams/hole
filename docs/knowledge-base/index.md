# Knowledge base

Hole is used on networks that block VPNs. The knowledge base collects what is known about those networks and about the
standards Hole relies on to get through them.

- [Recommendations for hostile networks](hostile-networks.md): where to host a server, which options to set, and how to
  diagnose a connection that fails.
- [ECH in practice](ech-in-practice.md): hiding the server's name with {term}`ECH`, the ways it fails, and what it does
  not hide.
- [Field reports](field-reports/index.md): dated records of failures on real networks, with the setup and the
  measurements.
